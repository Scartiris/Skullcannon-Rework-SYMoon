# 验收清单（Checklist，源自任务书 §10）

## 10.1 战役
- [ ] T2 不能招募颅骨魔炮
- [ ] T3 Foundry of Scythes 完工：可本地招募，2 回合，此时无攻城模式按钮
- [ ] T4 Foundry of Blood 完工：现存和新招颅骨魔炮都获得攻城模式
- [ ] T4→T5 升级：攻城能力不断档，T5 Overpressure 生效
- [ ] 拥有 2 座以上 T4/T5：能力不重复、不产生数值倍增
- [ ] 拆除/失去唯一 T4/T5：能力状态变化符合预期，不坏存档
- [ ] 全局招募、血军/特殊招募渠道不因建筑改动产生重复或非法条目

## 10.2 战斗
- [ ] 突击模式：约 280 射程、可移动射击、高机动，不像普通后排炮
- [ ] 攻城模式：约 500 射程、高抛，架设后不能正常移动，死区约 90
- [ ] 切换不恢复弹药、不复制弹药、不恢复生命、不改变经验
- [ ] 连续切换至少 10 次，不崩溃、不锁死射击、不永久失去移动
- [ ] 攻城模式被骑兵/近战冲脸时明显危险，玩家必须提前收炮
- [ ] 进入弓箭手/炮兵近战能补给，但冲反大型/精英近战会亏
- [ ] 0/20/50/80/100 WoM 分别测试，炮火差异符合分档且 tooltip 一致
- [ ] T5 顶档效果与普通 T4 顶档可区分，但不到一炮清整队的失控程度

## 10.3 AI 最低要求
- [ ] AI 默认保留突击模式，不出生即固定攻城模式
- [ ] AI 用炮不丢失原版基本作战能力（首版允许不用架设按钮）
